# Bobot

The fun go bot, currently a very early work in progress.

Using LLMs (heavily), but only as advisors, all code is written by hand, paying
attention to not just copy the LLMs suggestions blindly.

Uses Tromp-Taylor rules with forbidden suicides.

## Goals
- 13x13 only, for starters
- Neural net trained by self-play only
- Should beat my 3d friend
